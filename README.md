# Data-Analysis-case-
Pequeño proyecto de analisis y ciencia de datos // small data analysis and data sciencie proyect


## 🇪🇸 Español

Análisis de emisiones de **CO₂ per cápita** utilizando el indicador `EN.GHG.CO2.PC.CE.AR5` de **World Bank Open Data**. El proyecto aborda las etapas de **Data Understanding y Data Preparation de CRISP-DM**, incluyendo adquisición mediante API, normalización, separación de países y agregados, análisis de valores faltantes, outliers y duplicados, y almacenamiento en **SQLite**. Se analiza especialmente el valor extremo de **Palau en 2012**, evaluando su posible origen sin descartarlo automáticamente.

**Tecnologías:** Python, Pandas, NumPy, Requests, SQLite y Jupyter Notebook.

## 🇬🇧 English

Analysis of **CO₂ emissions per capita** using the `EN.GHG.CO2.PC.CE.AR5` indicator from **World Bank Open Data**. The project focuses on the **Data Understanding and Data Preparation stages of CRISP-DM**, including API data acquisition, normalization, separation of countries and aggregates, analysis of missing values, outliers and duplicates, and storage in **SQLite**. A particular focus is placed on the extreme value recorded for **Palau in 2012**, evaluating its possible origin without automatically removing it.

**Technologies:** Python, Pandas, NumPy, Requests, SQLite, and Jupyter Notebook.
